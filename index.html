Mark Clifton Homes — design options

Four standalone page previews share the same content, photography, and video assets. Open any option below to review layout, typography, and tone. This file is intended as your site entry point (index.html) when hosting so visitors land here first.

Hosting: deploy the whole project folder (including __originals/) so every option loads correctly. The hub is index.html; Option A (dark classic) lives at index-dark.html.

  1. Option A — Dark classic index-dark.html

    Cinematic full-screen video hero, near-black palette, gold accents — the original luxury “film” direction.

    • Layout: Centered hero over video; full-width stats band; balanced about grid with decorative frame; 3-up services grid; organic mosaic gallery.
    • Type: Cormorant Garamond + Montserrat.
    • Testimonials: Infinite horizontal ticker over video.
    Open preview
  2. Option B — Light classic index-light.html

    Same structure and sections as Option A, with a warm ivory ground and charcoal UI — for clients who want the classic layout in a lighter theme.

    • Layout: Identical to Option A (hero, stats, about, services, mosaic gallery, ticker testimonials, communities, contact, footer).
    • Type: Cormorant Garamond + Montserrat.
    • Testimonials: Same infinite ticker; nav switches from light-on-video to dark text when scrolled.
    Open preview
  3. Option C — Editorial index-editorial.html

    Magazine-style rhythm: split hero, overlapping about card, horizontal services strip, uniform gallery grid.

    • Layout: ~55/45 split hero (video + copy panel); stats rail inside hero; asymmetric about with overlapping copy; horizontally scrollable service cards; 3×4 editorial gallery; 2-column testimonial cards (no ticker); simplified footer.
    • Type: Fraunces + DM Sans; bronze accent on warm paper tones.
    • Testimonials: Static grid on a scrim over video (stronger readability than ticker).
    Open preview
  4. Option D — Architectural index-architectural.html

    Structural, gallery-wall feel: hero plinth with big numerals, bento services, modular grid, stacked quotes.

    • Layout: Full-bleed hero + bottom plinth (headline + oversized stat tiles); vertical side label; full-bleed about image then narrow centered copy; bento services (one large, two small); strict equal-cell gallery; single-column stacked testimonials; monospace communities strip; contact with vertical rule; minimal footer.
    • Type: Syne + IBM Plex Sans; cool charcoal with champagne line accent (not gold).
    • Testimonials: Vertical stack with rules — “prestige print” pace.
    Open preview

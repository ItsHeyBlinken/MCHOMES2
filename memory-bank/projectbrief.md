# Project Brief — Mark Clifton Homes Website Redesign

## Client
Mark Clifton Homes, Inc.  
3419 Westminster #26, Dallas, Texas 75205  
Tel: 214.532.8989 | info@markcliftonhomes.com

## Project Goal
Full redesign of markcliftonhomes.com as a modern, professional, luxury single-page HTML website.

## Deliverables
- `index.html` — **hub / table of contents** for client review (default entry when hosting; links to all options)
- `index-dark.html` — dark “classic” layout (Cormorant + Montserrat, mosaic gallery, testimonial ticker)
- `index-light.html` — same layout as dark classic, light palette
- `index-editorial.html` — alternate layout: split hero, paper editorial theme (Fraunces + DM Sans), horizontal services, uniform gallery grid, testimonial cards
- `index-architectural.html` — alternate layout: hero plinth + side label, cool charcoal theme (Syne + IBM Plex Sans), bento services, modular gallery, stacked testimonials
- All design pages: standalone single-page HTML, no build tooling required

## Key Requirements
- Video background hero using `__originals/480p/mp4/file.mp4`
- All home photography from `__originals/` directory integrated into gallery
- Auto-scrolling testimonials (left to right, infinite) with video background
- Testimonials content from `Testimonials.md`
- Modern luxury aesthetic: dark palette, gold accents
- Google Fonts: Cormorant Garamond + Montserrat
- Mobile responsive
- AOS scroll animations
- Gallery lightbox
- Contact form

## Sections
1. Fixed navigation
2. Full-screen video hero
3. Stats band (100+ projects, Best Builder 2010–2025, D Magazine, CGB)
4. About / credentials
5. Services (New Construction, Renovation, Commercial)
6. Photo gallery (12-image mosaic grid + lightbox)
7. Testimonials (infinite auto-scroll ticker, video background)
8. Communities served
9. Contact form
10. Footer
